# Music-Player-
 Music Player Project

I'm excited to share my latest project - a fully responsive Music Player built using HTML, CSS, and JavaScript!

What I Built:

A modern, clean, and interactive music player that allows users to:

Play / Pause songs

Switch to Next / Previous track

Control volume

View song title & duration

Track progress with a dynamic progress bar

Enjoy a smooth, responsive layout for mobile and desktop

Front-End Highlights:

Custom Ul with clean and minimal styling Smooth animations and polished interaction effects Fully responsive design for all device sizes

This project helped me strengthen my skills in Ul design, event handling, DOM manipulation, and responsive layout techniques.
